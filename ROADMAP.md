# Roadmap

## Fase 1 — Padronização (Concluída)

- [x] Criar scaffold completo do template.
- [x] Criar e fortalecer `AGENTS.md`.
- [x] Criar templates de ADR, experimento, assessment, nota de estudo e executive brief.
- [x] Criar templates de issues e pull request.
- [x] Adicionar verificações mínimas de Markdown e links.
- [x] Documentar convenções de cada área.

## Fase 2 — Migração

- [ ] Classificar conteúdo dos repositórios existentes.
- [ ] Separar estudo, experimento, avaliação e decisão.
- [ ] Criar ADRs retroativas somente para decisões ainda relevantes.
- [ ] Registrar fontes, lacunas e limitações.
- [ ] Popular índices e referências cruzadas.

## Fase 3 — Automação incremental

- [ ] Avaliar validação de front matter após uso real.
- [ ] Avaliar atualização automática do índice de ADRs.
- [ ] Avaliar compilação de diagramas como código.
- [ ] Automatizar apenas problemas recorrentes observados.

## Fase 4 — Evolução

- [ ] Adotar specs em trabalhos complexos.
- [ ] Consolidar assessments comparativos.
- [ ] Integrar executive briefs a decisões relevantes.
- [ ] Avaliar MkDocs somente quando a navegação no GitHub for insuficiente.

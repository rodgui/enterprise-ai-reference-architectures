# Especificações

Use specs para implementação, automação, laboratório complexo, definição de plataforma, framework ou trabalho multi-etapas.

## Estrutura

```text
NNN-capability-name/
├── spec.md
├── plan.md
├── tasks.md
└── validation.md
```

- `spec.md`: problema, objetivo, requisitos, exclusões e critérios de aceite.
- `plan.md`: estratégia, entregas, dependências, riscos e decisões pendentes.
- `tasks.md`: tarefas pequenas, ordenadas e verificáveis.
- `validation.md`: mapeamento entre requisitos, evidências e status.

Não use spec para uma nota de estudo comum ou uma pequena correção documental.

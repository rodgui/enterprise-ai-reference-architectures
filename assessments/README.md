# Assessments

Avaliações estruturadas de tecnologias, riscos, maturidade e alternativas.

- `technology-evaluations/`: tecnologias, produtos e serviços.
- `maturity-assessments/`: capacidades e estágios de maturidade.
- `risk-assessments/`: riscos e controles.
- `comparison-matrices/`: comparações ponderadas e rastreáveis.

Declare critérios, pesos, horizonte de validade, limitações, evidências e nível de confiança. Use [`../templates/assessment-template.md`](../templates/assessment-template.md).

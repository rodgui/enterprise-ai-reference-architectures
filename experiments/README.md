# Experimentos

Use esta área para hipóteses, PoCs, benchmarks e investigações ainda não consolidadas.

## Convenção

```text
exp-NNN-description/
├── README.md
├── hypothesis.md
├── environment.md
├── procedure.md
├── results.md
├── conclusions.md
└── artifacts/
```

Um experimento deve ser reproduzível, explicitar limitações e manter evidências. Não o apresente como padrão aceito. Use [`../templates/experiment-template.md`](../templates/experiment-template.md) como ponto de partida.
